# Portfolio

Лэндинг-портфолио на React + Vite + TypeScript.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173](http://localhost:5173) в браузере.

## Сборка

```bash
npm run build
npm run preview
```

## Настройка

Все данные сайта (имя, контакты, проекты, навыки) находятся в файле `src/data.ts` — отредактируйте его под себя.

## Структура

- **Hero** — главный экран с приветствием
- **Обо мне** — краткая информация
- **Проекты** — 10 карточек работ со ссылками на отдельные страницы
- **Страница проекта** — слева: название, описание, URL репозитория и публичный URL; справа: слоты (скриншот сверху, технологический стек с описанием снизу)
- **Навыки** — технологии и инструменты
- **Контакты** — email и соцсети

Данные проектов и слотов редактируются в `src/data.ts`. Для изображений в слотах укажите поле `image` (путь к файлу в `public/`).
